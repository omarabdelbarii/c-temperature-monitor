# C Temperature Monitor

A beginner C programming project that simulates
an embedded temperature-monitoring system.

## Purpose

Learn C programming, Git, and open-source
development workflows.

## Requirements

- C compiler (Clang or GCC)
- Terminal

## Build

clang -std=c11 -Wall -Wextra -Wpedantic \
main.c -o temperature-monitor

## Run

./temperature-monitor

## Current Features

- Simulated temperature reading
- Terminal output

## Planned Features

- Temperature alert thresholds
- Basic automated testing
